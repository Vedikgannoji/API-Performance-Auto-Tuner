# Security reporting

This is an unqualified beta candidate. Use loopback deployments with one worker. Shared caching requires explicit public-read approval and correct invalidation rules.

Use GitHub private vulnerability reporting if enabled. Otherwise open a minimal issue requesting a private contact without exploit details, credentials, private payloads or sensitive routes. A response SLA and private contact channel have not yet been established.

Include version, OS, sanitized configuration, expected boundary and a disposable reproduction. Do not expose the management listener to reproduce an issue.
